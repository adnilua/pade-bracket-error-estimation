# From Alternating Bounds to Rational Error Estimates

Independent mathematics research on the relationship among alternating-series
error bounds, continued fractions, and Padé approximations.

## Main Idea

This project develops a unified rational-approximation perspective on the
three methods and proposes a Padé-bracket error estimate based on the gap
between adjacent rational approximations.

When adjacent approximations bracket the target function, the gap gives a
rigorous error bound; otherwise, it can be used as a numerical error estimator.

## Case Study

For ln(1+x) at x=1, I compared Taylor and diagonal Padé approximations.
A [3/3] Padé approximant achieved an absolute error of approximately 2.5e-5,
compared with 0.193 for the second-degree Taylor truncation.
